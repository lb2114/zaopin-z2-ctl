# zaopinctl

CLI-утилита для настройки мыши Zaopin Z2 в Linux. Позволяет менять DPI,
переключать профили, задавать частоту опроса и время сна, а также читать заряд
батареи.

Обмен идёт через `/dev/hidrawX`. Устройство определяется автоматически по
VID:PID `3554:f527`, используется USB-интерфейс №1. Протокол частично восстановлен
по USB-захватам официального Windows-приложения.

## Сборка

Нужны:

- GCC;
- Make;
- `pkg-config`;
- `libsystemd` с заголовочными файлами;
- заголовочные файлы Linux с поддержкой `HIDIOCSOUTPUT`.

Из корня репозитория:

```bash
make
```

Исполняемый файл: `build/zaopin-z2-ctl`. Его можно запускать без установки:

```bash
sudo ./build/zaopin-z2-ctl dpi
```

Удалить результаты сборки:

```bash
make clean
```

## Установка и доступ к устройству

```bash
sudo make install
sudo udevadm control --reload-rules
```

По умолчанию установка создаёт:

- `/usr/local/bin/zaopinctl` — исполняемый файл;
- `/etc/udev/rules.d/70-zaopin-z2.rules` — правило доступа к устройству.

После перезагрузки правил переподключите USB-устройство. Правило использует
`uaccess`, чтобы дать доступ пользователю активного локального сеанса.
В таком сеансе команды можно выполнять без `sudo`:

```bash
zaopinctl dpi
```

Если доступ не предоставлен, например при работе вне локального сеанса,
команду можно запустить через `sudo`.

## Команды

Для чтения параметра достаточно его имени. Суффикс `show` необязателен:
`zaopinctl dpi` и `zaopinctl dpi show` выполняют одно действие.
Для батареи используется только `zaopinctl battery`.

| Параметр | Чтение | Изменение | Допустимые значения |
| --- | --- | --- | --- |
| Активный DPI-профиль | `zaopinctl profile` | `zaopinctl profile set N` | 1–6, в пределах включённых профилей |
| Профили и их DPI | `zaopinctl profiles` | `zaopinctl profiles set N` | Количество включённых профилей: 1–6 |
| DPI активного профиля | `zaopinctl dpi` | `zaopinctl dpi set N` | 50–26000, шаг 50 |
| Частота опроса | `zaopinctl freq` | `zaopinctl freq set N` | 125, 250, 500, 1000, 2000, 4000 Гц |
| Время до сна | `zaopinctl timetosleep` | `zaopinctl timetosleep set N` | 10–2400 секунд, шаг 10 |
| Заряд батареи | `zaopinctl battery` | — | Проценты и признак зарядки |

`profiles` выводит список включённых профилей с их DPI. Команда `profiles set N`
меняет число включённых профилей.

### Примеры

```bash
# Показать профили и заряд батареи
zaopinctl profiles
zaopinctl battery

# Включить три профиля, выбрать второй и задать ему 800 DPI
zaopinctl profiles set 3
zaopinctl profile set 2
zaopinctl dpi set 800

# Установить частоту опроса 1000 Гц
zaopinctl freq set 1000

# Установить время сна 5 минут — значение передаётся в секундах
zaopinctl timetosleep set 300
```

Без установки замените `zaopinctl` на `./build/zaopin-z2-ctl`.

## Известные ограничения

- Примерно после пяти секунд неподвижности мыши чтение конфигурации перестаёт получать ответы. Автоматическое восстановление связи не реализовано. Для использования необходимо пошевелить мышью. Это состояние наблюдалось независимо от настраиваемого времени сна `timetosleep`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `src/main.c` | Запуск программы, открытие устройства и выполнение команды |
| `src/cli.c`, `include/cli.h` | Разбор аргументов, справка и выбор операции |
| `src/hid.c`, `include/hid.h` | Поиск и открытие hidraw-устройства через `libsystemd` |
| `src/device.c`, `include/device.h` | Отправка и приём отчётов, чтение и запись параметров, вывод значений |
| `src/protocol.c`, `include/protocol.h` | Кодирование значений, контрольные суммы и проверка ответов |
| `udev/70-zaopin-z2.rules` | Правило доступа к устройству |
| `Makefile` | Сборка и установка |
